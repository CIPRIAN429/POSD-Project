## Before sharing the initial version

- Start the application in WSL using the documented command.
- Run the policy and Django suites against PostgreSQL.
- Walk through all three application roles in both organizations.
- Review direct URL access, private downloads and the failure demonstration.
- Confirm that application text, fixture content and PDF handouts are English.
- Share the source and instructions; exclude `.env`, local credentials, generated media and caches from the repository.

## Final course submission

- Confirm the team name and theme are recorded in the registration sheet by **20 October 2026**. This is the registration deadline, not a supplied final delivery date.
- Read the separate essay instructions before preparing final essays.
- Produce one PDF combining the three individual scientific essays.
- Keep each essay at 1.5-2 pages including 3-5 relevant research references.
- Apply IEEE citation style and the specified formatting from the essay outline.
- Number and cite any figures, equations, tables and algorithms; keep their combined size within 10% of each essay.
- Produce the PowerPoint for the seven-minute presentation.
- Rehearse the eight-minute demonstration and recovery from policy-service failure.
- Upload code and relevant project files or provide the accepted public Git repository.
- Provide a working dataset link to the repository's synthetic `data/` directory.
- Verify all submission links without relying on a signed-in private session.

The final essays and slide deck are intentionally pending until the team has reviewed the application and collected its own evidence.
